# Thread

Swing on a vine, let go at the right moment, fly through the gap.
One input: tap. Canvas 2D, no dependencies, no build step.

## Install on iPhone
1. Open the GitHub Pages URL in Safari
2. Share -> Add to Home Screen
3. Fullscreen, portrait, works offline

## Design notes
Difficulty ramps over the first 45 gaps: opening 300px -> 118px, trunk
spacing 600px -> 480px, back-to-back walls appear, vine gives way sooner.
Measured release window: 415ms -> 214ms.

Levels are generated by simulating a real release — the gap is placed where
that shot passes, the next branch on the same flight path — so every gap is
threadable by construction.
