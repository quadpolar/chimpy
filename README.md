# Thread

Swing on a vine, let go at the right moment, fly through the gap.
One input: tap. Canvas 2D, no dependencies, no build step.

## Install on iPhone
1. Open the GitHub Pages URL in Safari
2. Share -> Add to Home Screen
3. Fullscreen, portrait, works offline

## Design notes
Difficulty ramps over the first 45 gaps: opening 250px -> 92px, trunk
spacing 480px -> 400px, back-to-back walls appear, vine gives way sooner.
Measured release window: 442ms -> 197ms.

Levels are generated by simulating a real release, so every gap is
threadable by construction. The 430px catch radius was set by measuring the
closest approach of 16,000 valid releases — it connects 98.9% of the time.
