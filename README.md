# Thread

Swing on a vine, let go at the right moment, fly through the gap.
One input: tap. Canvas 2D, no dependencies, no build step.

## Files
- `index.html` — the whole game
- `manifest.json`, `sw.js` — installable, works offline
- `icons/` — home screen icons

## Install on iPhone
1. Open the GitHub Pages URL in Safari
2. Share -> Add to Home Screen
3. Launches fullscreen, portrait, no browser chrome

## Design notes
Difficulty ramps over your first 45 gaps: opening shrinks 320px -> 148px,
trunks close from 700px -> 560px apart, back-to-back walls appear, and the
vine gives way sooner. Measured release window: 383ms -> 190ms.

Levels are generated by simulating a real release — the gap is placed where
that shot passes, and the next branch on the same flight path — so every gap
is threadable by construction.
